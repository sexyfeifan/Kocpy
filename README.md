# New Kocpy 2.0

一个本地优先的 macOS 素材工作台。参考 DiskHop 的简洁备份流程与 Kocpy 的项目管理，重做信息架构和视觉设计，沿用 Kocpy 原始图标。

## 启动

Apple Silicon 本地应用：`release/mac-arm64/New Kocpy.app`。安装包：`release/New-Kocpy-2.0.0-arm64.dmg`。

开发环境：macOS、Node.js 22、npm。首次安装依赖需联网下载 Electron / FFmpeg。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run pack
npm run dist
```

当前应用包为本地构建，未经 Apple Developer ID 签名及公证。不会自动替换旧版 Kocpy，不含自动更新或绕过系统安全设置的安装脚本。

## 已实现

- 深石墨 / 浅色双主题；键盘快捷键；保留 Kocpy 图标。
- 工作台、传输队列、项目、素材库、报告中心、设备与偏好设置。
- 多素材源分别排队，每个任务最多 4 个目标并行写入；任务之间串行执行。
- 素材卡模式（独立唯一目录）、项目模式（项目 / 日期 / 机位 / 素材目录）、目录模式（保留相对结构，不删除目标额外文件）。
- SHA-256 / MD5 / SHA-1 流式校验；每个目标文件回读比对，已存在文件也必须校验。
- 同名内容相同时跳过写入，不同时报错或创建副本，绝不静默覆盖。
- 源 / 目标真实路径与包含关系检查；拒绝源符号链接和目标越界符号链接。
- 取消、优先级、失败重试、重启后中断提示；重试会重新验证完整文件并重拷未完成文件。
- 串行原子存储、上一版本 `.bak` 恢复；应用运行时阻止系统空闲挂起。
- 已挂载磁盘识别、容量信息、Finder 定位、任务使用中的设备禁止推出。
- PDF 备份报告及包含每个目标哈希的 JSON 清单。
- 已校验副本的 H.264 / ProRes Proxy 生成；720p / 1080p 最大高度，保留宽高比、音轨和元数据。

## 工作流

1. 点击「新建备份」（⌘ N），选择或拖入一个或多个素材文件夹。
2. 应用扫描文件数量和容量，选择最多 4 个目的地。项目模式可套用拍摄项目预设。
3. 确认算法与同名策略，开始备份。任务详情查看每个目的地与校验日志。
4. 任务完成后从「报告中心」导出 PDF 或 JSON；从「素材库」定位副本或生成代理。

项目预设只保存配置，不会在保存时预先写入硬盘。正式开始任务时才创建目录。

## 安全与边界

- 首版不包含云上传、短信通知、LUT/CDL、剪辑软件集成、自动 NAS 扫描或 SMART/RAID 健康检测。
- NAS 需通过 Finder 挂载，按普通目录备份。未实施或宣称 ASC MHL / Netflix 合规。
- 不是字节级断点续传：取消/失败后，完整文件重新校验；未完成文件重拷。
- 不自动删除源卡、不格式化、不做破坏性镜像同步。
- 默认包括隐藏文件，但排除 `.DS_Store`、`._*`、`.Spotlight-V100`、`.Trashes`、`.fseventsd`；符号链接与特殊文件会明确报错。
- 校验报告反映执行时状态；不是实时介质健康承诺。至少保留两个独立物理设备的副本；同一硬盘不同目录不构成独立冗余。
- iCloud 文件应先在 Finder 下载；网络盘应保持挂载。建议通过「选择文件夹」授权访问。扫描等待超时会提示重试。
- 原有两个工程仅作为参考，未改动其文件；新应用数据位于 `~/Library/Application Support/New Kocpy/`，旧应用的数据不会自动导入。
- 源只读指应用不主动写入源。系统的文件访问时间、iCloud 下载缓存等行为由 macOS 管理。
- 应用关闭窗口时，进行中的任务继续运行；退出前需取消备份或等待代理结束。
- 代理基于内置 FFmpeg，专有 RAW 编解码并不保证可用；不宣称剪辑软件工程级时间码完整对接。

## 架构

- `src/main/backup/`：独立于 Electron 的安全检查、扫描、流式备份、校验及队列。
- `src/main/index.ts`：受限 IPC、原生对话框、任务持久化、PDF 导出和窗口生命周期。
- `src/main/storage.ts`：串行写入、原子替换及备份恢复。
- `src/main/proxy.ts`：内置 FFmpeg 代理生成。
- `src/renderer/src/`：React / TypeScript 界面，直接连接 Electron IPC，无假数据服务。
- `tests/`：真实临时文件系统测试、报告转义及代理生成 / 解码测试。
- `docs/RESEARCH.md`：参考资料与取舍；`docs/VERIFICATION.md`：验证结果与未测边界。

## 发布说明

2.0.0 是首个整合后的可运行版本。已在当前 Apple Silicon Mac 验证；外置介质意外拔出、物理断电、数 TB 长时任务、各型号相机 RAW 和 Intel 尚未实机验证。生产使用前，请先以非唯一素材做小批量备份与抽查。
