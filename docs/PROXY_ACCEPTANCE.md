# 代理专项验证

所有样本由程序生成；不得对生产素材、唯一副本或现有剪辑项目执行破坏性测试。自动测试的通过不能替代 NLE 实际导入和可牺牲物理设备测试。

## 准确安装包与可保留样本

```bash
npm run test:proxy-acceptance -- \
  --app /absolute/path/Kocpy.app \
  --result /absolute/path/new-proxy-result.json \
  --keep-fixtures --plan
```

确认应用路径后移除 `--plan` 执行。应用只读，样本位于独占系统临时目录；已有结果不会覆盖。不加 `--keep-fixtures` 会删除本次独占样本，JSON 中的路径仅为历史记录。保持样本时，结果中的交付目录和高级转换路径可供手动导入。不要公开含本机路径的原始结果。

样本包含 25 fps 双音轨源、H.264、ProRes Proxy／LT、软件 24 fps／旋转／自定义时间码／身份 LUT，及自动硬件或明确软件回退、去音轨／去时间码。检查完整源哈希、输出 SHA-256、转码后的媒体对比、独立取消和交付目录。故意改动 LUT 必须被拒绝。

## NLE 实际导入记录

专项命令使用当前源码中的验证逻辑与指定安装包的媒体运行时，并记录安装包版本、payload SHA-256 和 Electron 版本；它不替代安装包主界面的交互测试，也不证明源码与旧包功能完全一致。

在 Resolve、Premiere、Final Cut 新建独立合成测试项目，导入保留的源、标准代理和高级输出。分别记录软件版本、实际编码器、帧率、起始时间码、音轨数量、旋转／比例、导入和重新链接结果；预览首尾帧及音频。CSV／XML 的结构检查并不代表实际导入或支持自动绑定代理。自定义帧率、裁切和 LUT 可能不适合原素材重新链接，不应视为透明代理。

未安装的软件标注“未执行”；固定标准样本的历史 Resolve 结果不覆盖新增高级组合。禁止为取得通过结论而导入生产项目、绕过哈希门禁或修改原素材。

## 故障覆盖矩阵

| 场景 | 自动覆盖 | 真实验证边界 |
| --- | --- | --- |
| 编码器兼容性失败／自动回退 | 注入子进程退出；仅自动重试并记录编码器 | 实际硬件成功依机器，硬件不可用不得伪称成功 |
| 空间不足／权限／I/O／损坏输入 | 错误注入，拒绝重试，清理本任务暂存，已有文件保持不变 | 非物理耗尽、拔盘或 NAS 中断 |
| 输出同名与取消 | 排他发布与真实 FFmpeg 独立取消 | 非断电耐久性证明 |
| LUT 改变 | 真实内容变更哈希拒绝 | 不修改原 LUT |
| 介质／UUID／NAS | 见真实介质测试协议及现有恢复回归 | 仅可牺牲卷；拓扑未知不是独立物理副本 |

[真实介质协议](HARDWARE_TEST.md)需要操作者指定明确的可牺牲卷；当前未指定卷时不执行写入、拔盘、空间耗尽或 NAS 中断测试。测试工具可用与实机测试完成是两件事。
