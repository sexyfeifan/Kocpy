# Kocpy 0.1.49

本说明描述本版已实现的功能与安全边界。准确安装包、附件摘要和公开状态以[同版 GitHub Release](https://github.com/sexyfeifan/Kocpy/releases/tag/v0.1.49)为准；构建、桌面及最终附件验收见[验证记录](VERIFICATION.md)。源码提交和说明文件不代表已发布或全部验收通过。

## 更舒展的界面

- 调整项目卡片摘要、表单与按钮区留白，减少内容贴边与密集控件挤压。
- 长标题、长路径和设备名称按可用宽度换行；侧栏字图保持原比例，不缩小界面来容纳内容。
- 深浅主题保持统一边界；布局不改变危险确认、校验或独立副本规则。
- 任务详情显示选定范围及未复制明细；长校验结论可换行，通知随打开的对话框展示，避免覆盖底部操作。扫描失败时自动显示错误位置。

## 当天新增设备，不改全部拍摄日

- 从项目的具体拍摄日进入“添加当日设备并备份”，填写日期、设备、可选机位和实际操作人，保存后直接选中。
- 只增加该日计划和汇总，不写入常驻设备，也不提前创建其他日期的空文件夹；实际备份才创建路径。
- 重复保存不重复添加；名称别名、自定义目录冲突或无效路径明确拒绝。
- 休息日恢复和未使用豁免调整保留审计；只让新增单元恢复应备份，其他已知机位维持原决定。未分机位计划不会被命名机位遮掉。
- 取消备份不删除已保存日计划；切换日期会重新检查设备是否属于当天。

## 混合日期先确认，再按范围备份

- 默认仍整卡备份。确认页只读识别日期线索，用户需要时再进行完整分析、日期修正和范围确认。
- 分析逐文件读取 SHA-256，会增加预检读盘时间；文件时间、路径和同名记录不等于已备份证据。
- 跨目录同名附属文件按关联组处理；未知／共享文件、不能拆分的摄影机包和关联不明的独立音频保守保留。选一天不保证只保留该日主视频，避免漏掉必要伴随数据。
- 历史副本须同项目、当前在线并重新校验内容与物理独立性。没有足够历史保护的未选内容，需要单独风险确认；始终记录实际操作人。
- 开始前及完成前重新核对冻结源范围，变化时停止，不自动猜测或修改源卡。

## 不把部分范围误称为完整副本

- 本次包含、未复制、历史已验证与尚未证实保护分别记录；随盘范围声明与报告保存所选范围、日期和操作证据。
- 部分范围校验通过不等于整卡完整，不计作完整卡副本，不允许据此清空或格式化素材卡。历史副本也不算成本次目标的新写入。
- 源素材和原 MHL 保持原样；不能删除范围声明或篡改旧清单来消除边界。普通新备份及接管都阻止将带部分范围／每日交付声明的目录重新算成整卡；目录搬运使用独立归档转存，跨 Mac 的原任务范围证据通过工作站包预检并合并。
- 日统计只累计本次纳入文件；确认日期进入相应拍摄日，未知归属留在任务日期并提示待确认。一个任务跨多个日期不代表多张卡。
- 任务与拍摄日报告同时保留设备名称及机位，避免临时设备的机位信息遗漏。

## 短片预览

- 短视频和静态图片使用合适的取图位置；常规取图失败时尝试首帧，避免一秒短片在片尾截帧失败。预览只写入缓存，失败信息仍与备份校验结论分别记录。

## 整卡后的每日交付

- 使用与拷贝前一致的保守关联闭包；未确认归属、共享文件和受保护素材组保留。
- 已筛选的部分范围任务不能冒充完整卡进行再次整理；先保留真实整卡副本。
- 旧待续交付的安全范围变化时，保留历史记录、阻止直接恢复并要求重新分析新建；不偷偷向旧目录追加内容。
- 修正新待执行交付的目录绑定：只记录已经存在的目的地父目录，Media 创建后再记录子目录，保证待执行记录可被工作区合法保存。

## 使用与验证限制

- 日期识别不是自动拍摄事实，跨午夜、错误时钟、时区或格式不支持时必须人工确认；无法可靠判断的关联内容优先保留。
- 保留源只读、逐目的地独立回读、卷身份检查、路径约束、源变化检查和可追溯范围，不用静默忽略来获得“通过”。
- 未取得 Developer ID／Apple 公证，当前仅使用 ad-hoc；不宣称原生 Intel、任意摄影机格式、真实双外盘或 NAS 已被本版全面验收。已执行与未验证范围分别记录。
- 安装前核对同版 `SHA256SUMS.txt`；使用自己的非生产素材与介质复验后，再用于正式工作。操作步骤见[使用手册](USER_GUIDE.md)。
