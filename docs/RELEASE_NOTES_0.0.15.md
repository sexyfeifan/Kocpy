# Kocpy 0.0.15

0.0.15 是 Developer ID 签名前的发布候选加固版本。

## 新增

- 软件内新增“使用说明”，覆盖新建备份、传输、恢复、项目、素材库、代理、报告、存储、诊断与归档维护，并提供步骤、注意事项和页面直达入口。
- 工作站配置导入前执行大小、结构、状态、哈希、路径和记录规模校验。
- 每次工作站合并前自动保存完整本地快照，避免错误配置覆盖现有记录。
- APFS 与 exFAT 临时挂载卷双目的地压力验证记录。

## 验证

- TypeScript 类型检查通过。
- 51 项自动测试通过；实体卷测试保持显式启用。
- APFS/exFAT 双目标完成 256 MiB 大文件和 1,500 个小文件复制，并逐目标 SHA-256 回读通过。
- 旧版工作站包缺少新增可选字段时仍可合并；畸形、超限或不受支持的数据会在写入前拒绝。

## 已知限制

- 安装包尚未使用 Apple Developer ID 签名和公证。
- 实体读卡器、外置磁盘、SMB/NFS、物理拔盘、断电和 Intel 实机仍需后续验证。
