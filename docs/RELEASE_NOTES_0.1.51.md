# Kocpy 0.1.51

此标签为未公开候选，UTC 工作站持久化回归未通过，没有正式安装包。修复见 [0.1.52](RELEASE_NOTES_0.1.52.md)；不覆盖旧标签或掩盖失败记录。

## 拍摄归属日与项目时区

- 项目设置增加 IANA 拍摄时区、单个拍摄日的异地时区覆盖，以及 0–12 时的大夜参考分界。新项目预填电脑时区供确认；历史项目保持未记录，不自动假定北京时间。
- 拍摄归属日继续由操作人选择。大夜跨零点不自动切日；参考分界仅提示可能属于前一场，不自动分配、取消勾选或跳过文件。
- 日期分析将带明确 UTC 偏移的媒体时间、文件修改时间换算到确认的拍摄时区；无偏移的相机时间不擅自换算。保留原始内嵌时间线索，不修改源时间或内容。
- 新任务冻结项目／拍摄时区、拍摄归属日、登记电脑时区与当时偏移。修改日期／时区后重新分析筛选；主进程拒绝旧规则和新任务混用。旧任务、恢复范围、目录和历史快照不重写。

## 报告与跨 Mac 兼容

- 普通备份、当日交付、项目及归档转存报告采用带时区标识和 UTC 偏移的时间展示，归档报告不再固定使用北京时间。历史记录缺失时区时，重新生成的时间以 UTC 显示并明确标记；已经保存的 PDF／PNG 不改写。
- `.kocpyproject` 与工作站配置包保留项目／逐日时区和新素材卷的冻结时间上下文。旧格式可读取；旧记录不会被推断成当前电脑时区。交换双方建议升级到本版。
- 时区信息不增加副本数量，不证明原始整卡完整，不授予清卡资格；原 MHL 不修改，标准清单中的 UTC 时间仍保持 UTC。

## 界面

- 左侧栏移除账号名及 GitHub／小红书入口，集中放到设置页底部“作者与项目”。使用 GitHub 品牌标识和小红书平台图标，保留明确文字、键盘焦点与可访问标签。
- 软件内说明更新时区、大夜、历史未知和跨 Mac 操作；说明仍由用户点击展开，标题不附版本号。

## 验证与限制

本版公开状态与精确安装包验证见 [VERIFICATION.md](VERIFICATION.md) 和同版 Release。发布前须完成全量回归、双架构流水线、报告渲染和实际隔离桌面检查；源码候选不等于安装包已发布。

不根据素材自动推断拍摄地点、相机时钟偏差或无偏移时间的真实时区；参考分界不是自动收工规则。同一拍摄归属日仅设置一个拍摄时区，场次中途换地区时仍须逐组人工核对。时区换算依赖随应用运行环境提供的时区规则，不是时钟校准服务。无 Developer ID／Apple 公证；本版不宣称新增真实双 Mac、NAS／SMB、拔盘或摄录设备认证。
