# Kocpy 0.1.44

包含未公开 0.1.43 的全部高级代理功能：H.264 软件／自动／仅硬件编码、实际编码器证据、ProRes 档位、帧率／音轨／音频／时间码／旋转／比例、软件质量与冻结 LUT。高级项默认折叠，交付继续保留原始证据和严格阻断。

## 可复用代理验证工具

- 修复高级面板展开后 fieldset 溢出页脚的问题：原生禁用 fieldset 置于独立滚动容器，头部关闭和提交操作保持可达。

- 新增准确安装包专项命令 `test:proxy-acceptance`，只读应用、生成独占样本、结果排他写入，支持先预览及保留 NLE 导入样本。
- 双音轨标准源覆盖 H.264、ProRes Proxy／LT 与高级转换，记录实际参数、媒体信息、输出哈希及编码器，不输出缩略图 Base64。
- 补充自动编码回退、空间／权限／I/O／损坏输入故障注入及暂存清理回归；已有输出必须保持不变。
- 新增 NLE 导入记录与真实介质边界协议，明确区分格式检查、注入测试和真实设备／软件验证。

工具完成不代表真实 NAS、拔盘、物理空间耗尽、Premiere 或 Final Cut 导入完成。固定标准样本的历史 Resolve 结果不覆盖新增高级组合；本版没有身份签名／公证声明。
