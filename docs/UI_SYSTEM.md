# Kocpy GUI 设计与验收约定

本文件描述已经落入代码的界面约定。它不是未来路线图，也不替代实际 Electron 界面验收。

## 0.1.46 视觉与信息层次

- 冷银玻璃表面使用分层背景、细边框、内侧高光与克制阴影；侧栏和顶栏形成透明层次，内容面板保持足够底色与文字对比。
- 银色渐变用于主操作，蓝／青／紫等颜色区分功能入口。任务状态另使用蓝色活动、绿色内容校验、黄色需关注和红色失败，始终同时提供文字，不只依赖颜色。
- 复制使用蓝青色进度，独立回读使用绿色进度。工作台展示实际素材源与各目的地的真实阶段及进度，未知速度或预计时间保留未知状态，不播放模拟完成进度。
- 复制完成、已纳入内容校验通过、范围完整与物理独立副本要求分别表达。权限遗漏和未知存储关系不能由绿色图标、目标数量或玻璃装饰推定为达标。
- 全部样式延续原来的按钮、表单、任务详情和向导行为。侧栏字号与图标尺寸保持固定，增加视觉层次时由滚动、换行和分区容纳内容。

## 交互层级

- 主操作使用银色 `primary`；普通操作使用默认按钮；次要操作使用 `subtle`；不可逆记录操作使用 `danger`。紫色功能图标或焦点强调不代表主操作已执行。
- 图标按钮固定尺寸，并必须提供可访问名称。禁用按钮保留原因提示，不用隐藏按钮来掩盖未满足条件。
- 错误使用 `role="alert"`，完成反馈和空状态使用 `role="status"`；“已校验”“副本达标”和“物理独立”仍是不同事实。
- 输入、选择器和多行文本使用同一高度、圆角、焦点环和主题变量。每个表单控件必须由可见标签或 `aria-label` 命名。

## 弹窗与检查器

- 普通弹窗和危险 `alertdialog` 共用同一焦点栈：打开后焦点进入窗口，Tab/Shift-Tab 不越出，Escape 只触发可用的取消或关闭操作，关闭后返回发起位置。
- 有未提交输入的普通弹窗关闭前提醒；危险确认的“取消”本身不再触发第二次阻拦。
- 删除、修订清单等危险操作仍要求明确范围、确认文字或勾选，不把 Enter 设置为无条件默认执行。
- 媒体预览属于非模态检查器，不锁住主窗口键盘焦点。

## 窗口与密集内容

- 常规最小窗口为 1080×720；更小的显示器按实际工作区安全适配。普通窗口维持 1.4–2.0 宽高比，全屏交给系统管理。
- 侧栏字号和图标不随高度缩小，中间导航独立滚动。
- 表格头和数据行共用列轨、最小行高和数字对齐；窄窗口优先换行或横向滚动，不裁掉状态和下一步操作。
- 弹窗标题和底部操作固定可达，正文独立滚动；向导步骤在空间不足时横向滚动。
- 长中文、英文、素材卷名和路径允许省略显示或安全换行，完整路径仍可通过标题、详情或 Finder 操作读取。

## 深浅主题

- 背景、边框、强调色、警告色、焦点环和拖拽高亮必须来自已定义的主题变量。
- 深色和浅色都要检查普通、悬停、焦点、禁用、成功、警告和错误状态；不得只替换页面背景。
- 系统“减少动态效果”开启时关闭非必要动画和过渡。
