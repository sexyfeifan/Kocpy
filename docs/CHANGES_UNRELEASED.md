**0.1.50 已正式公开**。见[本版说明](RELEASE_NOTES_0.1.50.md)、[准确附件验证记录](VERIFICATION.md)和[正式 Release](https://github.com/sexyfeifan/Kocpy/releases/tag/v0.1.50)。以下保留本版构建前改动过程；其中历史“候选／待验”描述不覆盖最终验收结论，不改写旧标签或旧附件。

- 随盘项目链路：项目备份后汇编 `.kocpyproject`；历史项目手动完整核对补生成；逐项有意缺失修订保留原始证据；携盘到新 Mac 后完整核对并继承参考历史，再独立归档转存及导出 PDF／PNG。继承不伪造本机卡数、整卡完成或物理独立副本。详细边界见[使用手册](USER_GUIDE.md#16-随盘项目文件与携盘到另一台-mac)。

- 新改进：拍摄归属日与大夜语义、合法历史日选项、明确选择记忆、显式批量归属草稿、后台目录权威与按日证据一致性。详见[项目备份流程审阅](PROJECT_WORKFLOW_REVIEW.md)。新功能的实际界面和准确安装包门槛尚待完成，不以本文宣布通过。

- 后续源码修复：范围复核实时数据单列、任务先登记再启动、慢列表不回退新进度；推出要求同范围覆盖及冻结副本策略；归档清单完整 ID 与独占写入、完成标记；项目逐文件归属及 CSV 摘要语义；副本重关联后更新有充分冻结证据的待处理代理；删除预览明确保留转存及交付恢复记录；只读详情操作不制造未提交表单提醒。实际签名门禁断言布尔值，不再只检索键名。准确安装包和最终发布仍待门槛，不代表当前下载版已包含这些修改。

- 界面跟进：任务详情统计卡片补足统一内边距；后台筛选区与任务卡片明确分隔，源／目的地路径完整换行；首页后台活动的空状态与标题使用一致留白。同类完成摘要、归档当前文件、源／目的地选择卡片和操作消息一并调整，停止状态不再显示“正在计算速度”。修复文件夹组织方式单选项继承通用表单高度和纵向布局的问题；后台错误文字不再被普通说明颜色覆盖。这些仍属于 0.1.50 源码候选，不代表安装版已更新。

## 已发布 0.1.49 的历史改动

## 界面布局

- 项目卡片、摘要、表单与操作区补足内边距；长标题、路径与密集控件在可用宽度内换行。
- 保持侧栏文字和图标尺寸，使用滚动和响应式布局，不以缩小整个界面解决拥挤。
- 深浅主题使用同一控件边界与状态语义，数据风险和确认要求不受外观变化影响。

## 当日临时设备

- 从具体拍摄日直接新增设备或机位，填写实际操作人后选中用于本次备份；同一保存幂等，不重复添加。
- 仅记录所选日期计划，不扩展常驻设备、不提前创建空目录；取消备份仍保留明确已保存的日计划。
- 日计划恢复休息日、撤销父级未使用豁免均保留审计；其他已知机位维持原决定。明确未分机位与命名机位可同时显示。
- 名称、路径别名和自定义命名冲突在保存前拒绝；换日期后不能继续使用不属于新日期的临时设备。

## 混合日期范围与证据

- 默认整卡；拷贝前只读查看日期线索，再由用户逐组确认日期和本次范围。
- 跨目录关联文件成组；未知／共享文件、摄影机包、关联不明的独立录音保守保留，不因未选日期被静默遗漏。
- 源文件逐一读取 SHA-256；历史跳过依据要求同项目当前在线副本重新验证及足够独立性证据。其他未选内容必须明确确认风险。
- 开始与完成前重新核对冻结源范围；记录包含、排除、确认人、日期和历史依据。源素材、原目录和原 MHL 均不改写。
- 部分范围不计为整卡完整副本，不获得清卡资格；任务、报告和随盘范围声明传递此边界。日统计只包含本次路径，未知日期留在任务日待确认。
- 整卡后每日交付复用保守闭包；部分范围任务不能冒充整卡再次生成交付。旧待续交付可保留读取，但范围改变时阻止恢复并要求重新分析新建。
- 新的待执行交付只记录实际已存在目录的身份，避免在 Media 目录尚未创建时提前写入不成立的子目录绑定。
