## 工作台外观与进度

- 冷银玻璃面板、银色主操作、功能图标配色和独立的状态语义色，覆盖深浅主题。
- 工作台显示真实素材源与多目的地进度，复制、独立回读、范围风险与物理独立副本要求分开呈现。
- 保持原侧栏字号和图标尺寸，密集内容通过独立滚动与换行容纳；延续现有向导、任务操作和确认规则。

## 素材目录扫描

- 新任务跳过 macOS 索引、废纸篓、文件系统事件、临时文件、文档修订及安装沙箱系统目录，避免选中素材盘根目录时被 `.Spotlight-V100` 权限错误中断。
- 子目录或条目遇到 `EPERM`／`EACCES` 时，记录排除证据并继续读取其他素材。根目录无法读取和其他读盘错误仍会明确报错。
- 界面、任务记录与报告保存排除路径、原因、权限码及大小未知标记；ASC MHL 的 `ignore` 保存精确排除路径。未读取目录的容量与子项数量标为未知。权限排除不会被算作完整素材备份或项目达标副本。
- 保留旧任务的冻结策略、源变化检查、符号链接限制及逐文件内容校验。
