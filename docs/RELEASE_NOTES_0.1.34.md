# Kocpy 0.1.34

真实双 Mac 返回闭环修复候选。

- 修复内置项目模板的稳定时间值 `0` 被误改，以及旧包缺少的空机位结构在首次提交后才被补齐，导致同一个工作站导出包第二次预检出现五项虚假模板冲突的问题。
- 外来模板在只读预检和正式合并前使用同一套确定性规范化；本机内置模板也通过相同边界进入交换状态。
- 相同包与相同冲突决定再次确认时复用原审计，不增加工作区修订、不追加审计，也不修改项目、任务、模板或删除墓碑。
- 保留有意使用新冲突决定再次合并的能力；这种操作会生成新修订与审计，不能被包级去重误拦截。
- 导入提示和确认按钮现在区分“核对既有审计”与“按当前决定提交”，准确说明两种行为。
- 新增内置模板零时间值、双程重复预检和导入界面语义回归。

## 候选状态与发布门槛

0.1.33 在 Mac B 正向验收通过后，于 Mac A 返回导入的第二次确认发现上述虚假模板冲突；项目和任务字节保持不变，但工作区修订和审计被错误增加，因此 0.1.33 不发布。0.1.34 必须重新完成本地隔离复现、双架构 CI、候选附件回下载以及真实 Mac B→Mac A→Mac B 往返和重启稳定性检查，才可创建正式标签与公开 Release。门槛关闭前 latest 保持 0.1.30。

本版本仍无 Developer ID 签名／公证。ad-hoc 签名只用于检查应用包结构，不能替代 Apple 身份、公证或来源确认。双机测试只使用隔离合成元数据，不读取、迁移、修改或删除生产素材。
