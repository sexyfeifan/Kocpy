# Kocpy 0.1.25

GUI 设计系统、键盘操作与全模块界面收口版本。

- 统一按钮、表单、选择器、状态徽章、空状态、表格、弹窗和检查器的尺寸、圆角、间距、焦点与深浅主题变量；修复密集页面中按钮拥挤、列高不齐和长路径溢出。
- 图标按钮必须提供可访问名称；禁用按钮保留原因提示。错误使用即时警告语义，完成与空状态使用非打断式状态语义。
- 普通弹窗和危险确认共用焦点栈：打开后进入第一个安全操作，Tab／Shift-Tab 不离开窗口，Escape 只执行可用的取消或关闭，结束后返回发起按钮。危险确认仍保留勾选、指定文字和范围检查。
- 项目操作菜单增加展开状态、菜单项目语义和稳定焦点锚点；取消项目删除后返回“更多项目操作”，不会把焦点丢到页面根节点。
- 素材媒体预览改为非模态检查器，不再错误锁住主窗口；全局新建和搜索快捷键在弹窗打开时不会越过当前上下文。
- 侧栏字号和图标比例固定，空间不足时仅导航区域滚动；主内容、长表格和弹窗正文使用各自滚动边界。最小窗口保留所有关键操作，不用缩小文字换取空间。
- 深色与浅色共同覆盖背景、边框、强调色、警告色、焦点、禁用和拖拽状态；表格数字使用稳定对齐，长中文、英文、素材卷名与路径可安全换行或滚动。
- 新增 UI 系统回归，检查组件依赖、弹窗命名、危险对话框范围、表单可访问名称、主题变量和响应式边界。公开 GUI 约定见 [UI_SYSTEM.md](UI_SYSTEM.md)。
- 软件内使用说明与公开手册同步说明界面、键盘和窗口规则；完整说明不会随工作台自动展开，仍只在用户点击入口后显示。

本版本不改变复制、独立回读校验、外部清单差异或物理副本判定的安全门槛。0.1.24 的接管映射预览、目录变化门禁、多副本关联和追加式审计继续保留。

仍无 Developer ID 签名／公证。真实 NAS、拔盘、断电、全部相机目录格式和所有第三方 MHL 变体未全面验证；最终发行附件、架构、测试结论和 SHA-256 以 [验证记录](VERIFICATION.md) 与 GitHub Release 实际附件为准。
