# Kocpy 0.1.16

0.1.16 解决项目测试清理、模板可用性和低高度窗口侧栏比例三个问题。项目删除仍限定在 Kocpy 内部记录，不会触碰任何素材文件或备份目录。

## 进行中项目也可安全删除

- “进行中”和“已归档”项目统一在项目卡片右上角菜单提供“删除项目记录”。
- 删除前先由主进程预览关联任务、代理、归档健康、变化与提醒数量。
- 用户必须勾选风险确认并准确输入完整项目名称。
- 存在等待、复制、暂停、校验中的备份任务，或等待、运行、暂停中的代理任务时拒绝删除。
- 删除范围仅包括 Kocpy 的项目配置、任务与文件索引、代理记录、归档健康记录、变化和提醒；素材源、备份目录、报告、MHL、项目归档包与冷归档文件均不修改。
- JSON 兼容记录与 SQLite 索引共同更新；索引持久化失败时恢复删除前记录。

## 高自由度项目模板

- 五个系统模板现在显示适用场景、设备组合、副本标准、检查表和完成动作差异。
- 可新建、重命名和编辑自定义模板，设置设备、机位、每台设备的素材卷前缀、预计卷数、目录规则、完成动作、开工/收工检查表和制作人员。
- 系统模板可复制为自定义模板、隐藏和恢复，不允许直接覆盖默认定义。
- 项目“保存为模板”先打开可编辑草稿，不再直接生成固定模板。
- 应用前显示逐项差异预览，可选择只覆盖部分配置；项目名称、拍摄日期和目的地路径不由模板修改。
- 自定义模板支持 JSON 导入与导出；主进程限制文件大小、模板数量、设备数量及必要命名变量。

## 侧栏保持正常比例

- 缩小窗口高度时不再缩小侧栏文字、图标、品牌和按钮。
- 中间功能导航拥有独立纵向滚动区域，底部设置、更新与作者入口保持原比例。
- 侧栏宽度在支持的最小窗口范围内保持一致，避免不同窗口尺寸出现明显跳变。
