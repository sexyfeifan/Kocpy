# Kocpy 0.1.24

专业接管、外部差异与副本关联加固版本。

- 单卷、单日与整项目接管新增逐卷映射预览，可修正拍摄日期、设备、机位和素材卷名称；缺少必需字段或重复映射时禁止写入。
- 预览生成文件清单与识别结果 SHA-256 摘要。开始接管时重新比对，全部读取完成、数据库写入前再次扫描；目录在过程中变化会整批停止，不产生半接管记录。
- 相同完整哈希的不同路径只有在用户确认关联规则后才合并为同一逻辑素材卷。接管保存卷 UUID；同一物理盘的多个目录不重复计数，没有同次存储拓扑证据时保持保守未知。
- 素材库重定位改为全卷完整哈希核对：先预检并显示旧／新位置供确认，确认后再次完整读取，期间内容变化不会更新任何记录。存在离线副本时更新其位置，全部旧副本在线时关联另一份健康副本；已经记录的路径拒绝重复添加。
- 接管、刷新、首次基线、外部清单修复、完整复校验、额外文件确认、经重要确认的 MHL 修订和重定位均写入追加式审计。记录包含路径、时间、操作人、摘要与关键结果，合并重复记录时仍保留双方历史。
- 刷新接管信息继续保留离线来源，不把缺失路径静默判断为安全；三次重复刷新保持素材卷与副本数量稳定。
- 接管弹窗与任务详情补充映射表、关联确认及审计历史；软件内说明和公开手册同步更新。

安全边界没有降低：外部清单缺失、大小不同或哈希不同仍不能普通确认跳过；MHL 修订仍要求重要确认并保留原始清单审计副本。所有开发和验收数据均为隔离生成数据，不修改真实项目、素材或生产清单。

仍无 Developer ID 签名／公证。真实 NAS、拔盘、断电、全部相机目录格式和所有第三方 MHL 变体未全面验证；最终发行附件、架构和校验值以 [验证记录](VERIFICATION.md) 为准。
