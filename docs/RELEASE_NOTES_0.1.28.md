# Kocpy 0.1.28

代理证据链与媒体交付可靠性版本。

- 代理入队冻结来源任务、相对路径、字节数、原哈希算法与校验值、媒体信息和全部转码参数；开始转码前完整重读源文件，拒绝路径、大小或内容变化。
- H.264 支持 MP4／MOV／MKV；ProRes Proxy 强制使用 MOV。预设会同时保存用途、编码、分辨率、码率、封装和命名规则。
- 代理完成后建立输出 SHA-256 与字节证据，并比较实际时长、帧率、时间码、音轨数、旋转、色彩空间和分辨率；无法取得的字段保持未知，不填入假默认值。
- 修正 FFmpeg 探测输出重复描述流时把单音轨计为双音轨的问题。
- 正式交付前重新完整校验全部代理输出并拒绝重名；交付媒体、Resolve/Premiere/FCPXML 清单和 `Delivery_Check.json` 通过同目录独占暂存、逐文件回读、落盘同步和原子改名发布。
- 交付包内清单引用最终 `Media` 目录，不再依赖转码时的原输出路径。旧代理任务缺少新证据时明确要求重新生成，不会把历史状态静默升级为可信交付。
- 固定 H.264 与 Apple ProRes 422 Proxy 合成样本已在本机 DaVinci Resolve 实际导入，分辨率、25 fps、2 秒时长、起始时间码和单音轨均正确。Premiere Pro 与 Final Cut Pro 未安装，对应 CSV/FCPXML 只声明格式检查，界面和报告均保留未实测标记。
- 项目“完成后生成代理”同步使用同一套源证据和参数快照，不再创建无法通过新预检的旧格式任务。

## 升级与限制

0.1.28 不修改原素材、项目目录或既有代理文件。0.1.27 及更早版本的已完成代理没有输出 SHA-256 证据，不能直接进入新的正式交付包；请从素材库重新加入队列。代理元数据检查不能替代原素材备份哈希和逐目标独立回读。

本版本仍无 Developer ID 签名／公证。Resolve 的实测结论仅覆盖固定隔离合成样本的媒体导入，不代表所有摄影机 RAW、插件或剪辑工程；Premiere CSV 与 Final Cut XML 尚无对应 NLE 实机导入验证。最终发行附件、架构、测试结论和 SHA-256 以 [验证记录](VERIFICATION.md) 与 GitHub Release 实际附件为准。
