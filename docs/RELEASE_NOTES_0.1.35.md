# Kocpy 0.1.35

发布链与现场验收加固正式版。

- 新增只读源码树卫生门禁：在测试和打包前检查 iCloud／同步冲突副本、AppleDouble、`.DS_Store` 和未完成云占位文件。发现问题时列出准确路径并停止，不自动删除或改写用户文件。
- GitHub Actions 更新到当前官方稳定代际，并固定到经过核对的完整提交 SHA，避免浮动标签和旧 Node 运行时影响后续双架构候选构建。
- 可选真实介质测试改为显式命令：执行前显示写入范围，要求一次性确认，只接受 `/Volumes` 下可写、非内置磁盘的精确挂载卷根目录，拒绝同一文件系统或同一物理整盘被重复算作多个本地目标。
- 真实介质测试只创建 256 MiB 合成大文件与 1,500 个合成小文件；通过生产备份引擎执行 SHA-256 独立回读，最后只清理本次随机测试目录，并输出不覆盖既有文件的结构化 JSON 证据。
- 结果明确记录文件系统、卷 UUID、设备标识、物理独立性结论和清理状态；网络存储的底层物理故障域无法由客户端证明时会如实标记，而不是冒充两块独立磁盘。
- 软件内使用说明的主标题与快速开始标识不再绑定版本号，避免每次更新把页面名称误看成另一份手册；实际应用版本仍在固定位置显示，各版变化继续保留在更新历史中。
- 0.1.32 引入的克制动效系统继续生效：页面、弹窗、提示、按钮、主题、开关和真实进度使用统一短动效；系统开启“减少动态效果”时全部关闭，且动画不参与任务状态或进度计算。

## 验收状态

0.1.35 已完成用户候选验收、自动化回归、原生 Apple Silicon／Intel 构建、安装包结构与隔离 GUI 核对，并以正式标签和 GitHub Release 发布。未执行的真实文件系统、NAS、断连、睡眠、空间耗尽和长时间压力项目仍明确保留为未验证，不会因正式发布而记为通过。

本版本没有修改复制、回读校验、MHL、项目记录或归档算法，也不迁移真实数据。当前仍无 Developer ID 签名或 Apple 公证；ad-hoc 签名只用于候选包结构验证，不能替代 Apple 身份与公证。
