# Kocpy 0.1.40

## 严格代理交付

- 区分代理生成完成、交付待确认和禁止交付。主进程重新检查源证据、参数快照及实际输出证据，不信任历史绿色标签。
- 音轨缺失、时长或帧率异常、必要输出媒体信息缺失阻止交付；剪辑代理的时间码或音轨数量变化也会阻止交付。
- 可豁免的元数据警告须填写例外交付原因。操作人、时间、警告和证据摘要绑定保留在清单及交付报告中；证据或参数变化后确认失效。
- 旧记录继续可读，缺少证据时要求重新生成；文件哈希校验不可豁免。
- 更新构建工具链中 brace-expansion、fast-uri、undici 的兼容安全补丁。
