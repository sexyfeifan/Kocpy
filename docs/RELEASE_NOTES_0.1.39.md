# Kocpy 0.1.39

0.1.39 是界面边界与使用说明整理版本，不改变素材复制、校验、恢复、归档或报告的安全语义。

## 界面修复

- 偏好设置的保存状态移到卡片标题区，不再越出内容内边距或压住分隔线。
- 新建备份的手动路径添加入口补齐可见按钮边界；素材卷卡片的添加／已选状态使用一致的图标容器。
- 普通备份与项目备份选择卡提高未选中边界辨识度，并统一图标容器、选中标记、悬停与键盘焦点状态。

## 使用说明

- 软件内更新历史改为按版本排列的折叠栏，默认全部收起；版本号和标题始终可见，展开后查看详细内容。
- 继续保留 0.1.31–0.1.38 的历史更新，不删减原有安全边界说明。

## 验证范围

本版源码全量回归为 519 项通过、4 项按真实硬件或压力条件跳过；类型检查、生产构建、源码／媒体来源门禁、依赖审计、大型 PDF 与报告产物检查均通过。双架构安装包、签名结构、包内隔离运行时和正式附件以同版验证记录及 GitHub Release 为准。真实介质、NAS、断连、拔盘、睡眠、空间耗尽和全部文件系统矩阵没有因此宣称完成。
