# Kocpy 0.1.17

本版集中修复备份向导、目录落点、Finder 拖拽与实时传输体验，并优化全新文件的源读取。独立目标回读校验和已有文件保护保持不变。

## 清晰的来源统计与目的地

- 文件分类统计明确显示“个文件”，解释照片／RAW 分别计数及其他／附属文件的含义。
- 在设置目的地时选择普通或镜像方式，统一选择副本的父目录，并显示每个来源的最终路径。
- 新镜像任务保留所选源文件夹这一层，不加随机码和时间戳；普通备份仍按“源文件夹名_时间戳”创建目录，内部文件名不变。
- 不自动删除目的地额外文件，不静默覆盖冲突。多来源同名目录会提示分批处理。
- 旧镜像任务恢复／重试沿用原落点，不移动既有副本。

## 恢复 Finder 拖拽

- 源与目的地统一使用 Electron 支持的 `webUtils.getPathForFile` 解析路径，不再依赖已移除的 `File.path`。
- 拖入后由主进程确认真实文件夹，拒绝单个文件、无效路径和超量目的地，并提供反馈。
- 这是共用代码修复，不限于 x64。

## 实时详情与暂停反馈

- 详情不再优先显示打开时的静态快照，状态、速度、目标信息和进度使用实时任务数据。
- 拍摄项目素材卷明细增加进行中进度和速度，卷名可点击进入详情。
- 大文件按已确认写入字节更新进度；暂停／继续和任务阶段切换不再被进度节流丢弃。
- 哈希读取和断点前缀核对支持在块边界响应暂停；在校验尚为 0% 时暂停后也能恢复到正确校验阶段。
- 频繁进度更新不再持续推迟检查点保存。

## 安全的性能优化

- 全新文件在扇出复制时计算源哈希与 ASC MHL 所需 MD5，减少一次完整源读取。
- 已有文件、断点和失败目标重试保留预哈希比对路径；目标仍逐文件独立回读校验。
- 正确补齐部分写入，及时清理慢目标检测计时器，并在异常路径收尾打开的文件句柄。
- 隔离 256 MiB、4 文件、单目标样本在本机交替测试：预哈希再复制的复制阶段中位数 914 ms，合并读取为 853 ms。该样本含本地缓存影响，不是 Finder 对比，也不构成外接盘或 Intel 实机速度承诺。
