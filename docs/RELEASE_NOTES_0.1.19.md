# Kocpy 0.1.19

磁盘身份误报修复、安全恢复引导与项目操作布局改进。

## 修复磁盘 UUID 误报

- 任意子目录先解析实际挂载设备，再读取磁盘 UUID，不再把目录查询失败当作磁盘更换。
- 身份未知与身份不匹配分别提示；曾记录 UUID 的任务不会降级为只比较盘名或旧设备标识。
- 查询前后核对路径所属设备；原盘重连可再次检查，真实换盘仍停止写入。

## 让停止之后有明确下一步

- 恢复中心及任务详情提供“检查并恢复”，针对身份、离线、权限、空间、源变化、同名冲突及校验错误给出操作建议。
- 只读展示记录身份、当前 UUID、真实挂载点、权限与可用空间。检查不修改任务、素材或清单。
- 用户确认后仅重试未通过目标；后台重新检查，仍执行预检、断点验证和独立回读，不跳过安全保护。
- 换盘引导另建任务；接管记录分流至基线或清单处理。原错误与任务记录保留至正常处理，不以删除项目消除警告。

## 界面与相邻缺陷

- 本页帮助改为顶栏问号，默认不展开；侧栏完整说明入口保留。
- 项目卡片统一为带图标、等高的两列操作按钮，避免文字换行与图标缺失。
- 从项目卡片进入模板与交接时选中对应项目，避免误操作另一个项目。
- 复校验重新判断原盘在线状态，成功后清除旧任务错误；缺少完整哈希基线时拒绝将任务标为安全。
- 复校验与传输队列互斥，结束后继续处理等待队列。

## 验证与边界

148 项自动化测试通过，3 项可选测试跳过；arm64 原生与 x64 Rosetta 运行时的恢复、复制及独立回读检查通过。顶栏和项目卡片已实际查看，但恢复弹窗最终滚动、完整 GUI 重试链、最小窗口及深浅主题仍需人工复核，未宣称桌面验收全部完成。

具体测试、安装包及桌面验收范围见 [验证记录](https://github.com/sexyfeifan/Kocpy/blob/main/docs/VERIFICATION.md)。本次不更改素材或 MHL 修订规则。不具备 Developer ID 签名或公证；x64 Rosetta 检查不替代真实 Intel Mac 测试。
