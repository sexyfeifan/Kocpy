# Kocpy 0.1.32

界面动效基础与候选发行链加固版本。

- 建立统一的快速、标准和进度动效时长，以及适合专业工具的克制缓动曲线。
- 页面切换采用 4 px 短距离淡入；弹窗采用轻微上移与缩放；底部提示保持水平居中并从下方进入。
- 普通按钮、文字按钮和分段控件增加不改变布局的按下反馈；主题、开关与真实进度过渡改用同一套动效变量。
- 完整保留 `prefers-reduced-motion`：系统要求减少动态效果时，所有动画与过渡均关闭。
- 不引入 GSAP 或其他动画运行库。动画不驱动任务状态、不延迟确认、不推算传输进度，也不会隐藏错误。
- 无 Developer ID 候选包改为完整 ad-hoc 签名；CI 严格检查应用、辅助进程、框架和 Electron 运行权限。本地候选先在系统临时目录签名，再保持框架相对符号链接复制回输出目录。

## 候选状态与发布门槛

0.1.32 可以继续代码审查、自动化、双架构 CI 和隔离 GUI 验收，但它继承 0.1.31 的真实双 Mac 门槛。两台真实 Mac 尚未完成 A→B、B→A、冲突、重复导入、删除墓碑和重启核对前，不创建正式标签或公开 Release；GitHub Releases 的 latest 继续保持 0.1.30。

本版本仍无 Developer ID 签名／公证。ad-hoc 签名只保证应用包结构完整，不能替代 Apple 身份、公证或用户来源确认。所有写入验证使用隔离生成数据，不读取、迁移或删除生产素材。
