# Kocpy 0.1.15

0.1.15 改善传输任务的现场辨识与路径追踪，并为需要重新验收完整工作流的用户增加受保护的“已归档项目删除”能力。本版本不会扩大 Kocpy 对素材文件的修改范围。

## 传输任务更容易辨认

- 根据已经扫描并记录的文件分类显示任务图标：视频、照片/RAW、音频、混合素材和其他素材卷。
- 图标颜色继续表达任务状态：等待、复制、校验、暂停、完成、失败或取消，不用图标种类冒充任务结果。
- 旧任务会从现有文件记录补全素材类型统计；不会重新读取、重新哈希或修改素材。

## 完整源路径与目的地路径

- 传输列表的非紧凑任务条目直接显示完整源路径和所有目的地路径。
- 目的地优先显示实际写入并校验后的最终路径，能够反映同名处理产生的真实目录名称。
- 长路径自动换行，不以省略号隐藏；点击路径即可在 Finder 中显示。
- 任务搜索同时匹配卷名、源路径和目的地路径。

## 删除已归档项目记录

- “已归档”项目卡片新增删除按钮，适合清空 Kocpy 内部记录后重新执行项目创建、接管、备份和归档测试。
- 删除前显示包含项目名称和准确范围的重要确认；非归档项目没有删除入口。
- 存在等待、复制、暂停、校验中的备份任务，或存在未结束的代理任务时，主进程拒绝删除。
- 删除会清理 Kocpy 内部的项目配置、关联任务与文件索引、代理队列记录、归档健康记录、变化记录和提醒。
- 删除不会触碰素材源、目的地备份目录、PDF/JSON/CSV 报告、MHL/ASC MHL、项目归档包或冷归档文件。
- JSON 兼容记录与 SQLite 索引均更新；索引写入失败时会尝试恢复原 JSON 记录，避免只删掉一侧。

## 软件说明

- 软件内使用说明新增任务图标、完整路径和项目删除范围；所有模块仍然默认折叠，只有用户点击后展开。
- GitHub README 与完整使用手册同步更新到 0.1.15。

## 安装说明

- Apple Silicon：`Kocpy-0.1.15-arm64.dmg`
- Intel：`Kocpy-0.1.15-x64.dmg`
- 当前发布包尚未使用 Apple Developer ID 签名与公证；请只从项目官方 GitHub Release 下载。

完整操作步骤见 [Kocpy 0.1.15 使用手册](USER_GUIDE.md)。
