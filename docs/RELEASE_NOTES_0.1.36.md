# Kocpy 0.1.36

项目安全规则确认与大型 PDF 报告修复版。

- 编辑既有项目时先显示安全规则的准确差异，逐项列出原值和新值。真实规则变化必须填写实际修改人后才能保存，不再先出现难以理解的远程调用错误。
- 目录缺失与规则变更使用明确的组合操作；“保存新规则并创建缺失目录”“仅保存新规则”不会再混淆。若当前已保存规则本身缺少目录，可单独“只补齐原项目目录”，不采纳表单中尚未保存的目的地或其他修改。
- 已保存目录修复在创建前检查全部目的地。存在文件／目录冲突或离线目的地时整次停止，不先修改其他目的地；成功后重新检查结构。所有补齐操作只创建缺失文件夹，不移动、覆盖或删除素材。
- 单任务、拍摄日、项目报告、项目归档包及完成动作 PDF 统一改为从权限受限的唯一临时 HTML 文件加载。页面载入后立即清理，不再将大量明细和缩略图编码为超长 `data:` URL，从而修复 `ERR_INVALID_URL (-300)`。
- PDF 错误提示限制长度，不会把整份编码 HTML 暴露在界面中。报告失败仍与复制、哈希、逐目标独立回读和任务完成状态分离。

## 安全与兼容性

本版本不修改复制、哈希、逐目标独立回读、MHL、物理独立副本判定或既有素材记录，不迁移生产数据。项目规则门槛没有降低；修改人和追加式规则快照继续保留。当前仍无 Developer ID 签名或 Apple 公证，发布包使用的 ad-hoc 签名不能替代 Apple 身份与公证。

真实生产项目仅用于复现截图和只读元数据核对；开发和回归测试全部使用仓库外隔离合成目录，不读取、移动、覆盖或删除生产素材。最终安装包、架构、测试范围与 SHA-256 以 [验证记录](VERIFICATION.md) 和本 Release 实际附件为准。
