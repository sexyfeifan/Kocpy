# Kocpy 0.1.7

0.1.7 修复重复接管导致素材卷、文件数、容量和收工进度被重复累计的问题。此版本仍未使用 Apple Developer ID 签名与公证。

## 接管记录刷新

- 同一绝对路径再次接管时更新并整理原有逻辑素材卷，不再永久新增重复任务。
- 项目详情增加“刷新接管信息”，只扫描目录结构和整理 Kocpy 元数据，不重新计算素材哈希、不移动或删除素材。
- 刷新可以合并旧版本产生的无哈希重复记录，保留可信度最高且最新的有效基线。
- 同路径记录始终按一个素材卷统计；不同路径只有完整文件哈希一致时才合并为多个物理副本。
- 重复项目绑定路径同步清理；离线来源保留原记录，不会因刷新而丢失。

## 项目明细排版

- 素材卷明细增加明确的四列表头。
- 日期设备、素材卷、文件容量和可信状态使用固定列宽，上下行保持对齐。
- 项目详情提示刷新后的数据按唯一素材卷统计。
