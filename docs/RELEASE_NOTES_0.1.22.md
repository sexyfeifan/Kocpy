# Kocpy 0.1.22

普通备份与实时阶段反馈维护版本。

- 默认“普通备份”不要求创建项目；目录组织单独选择“按次保存（推荐）”或“保留源文件夹（镜像备份）”，开始前核对最终保存路径。
- 高级选项默认折叠，键盘焦点跳过折叠内容；逐文件哈希和逐目标独立回读不变，不覆盖已有不同内容。
- 容量读取失败或未知不再显示检查通过；开始前不将不同卷标识标绿为物理独立，最终仍按校验与存储证据判定。
- 暂停清空旧速度和预计时间；继续后重置采样窗口，不计入暂停时长。预计时间明确属于当前阶段，预检和无有效速度时显示横线。
- 列表、详情和项目明细使用一致阶段进度，未完成的99.x%不四舍五入到100%；暂停／继续明确显示命令处理中，最终以后台状态为准。
- 浅色警告增加对比度；项目日期选择兼容紧凑／横杠日期。更新内置与公开新手操作说明。

包含 0.1.21 的统一可信状态、保守副本计数、媒体运行时与对应源码分发、报告和窗口布局修复。

所有测试使用隔离生成数据；不更改用户生产记录、素材和原始清单。真实 NAS、拔盘、断电及全部相机格式未全面验证。无 Developer ID 签名／公证，不宣称零缺陷或硬件认证。以 [验证记录](https://github.com/sexyfeifan/Kocpy/blob/main/docs/VERIFICATION.md) 中的最终附件验收为准；未通过界面与发布门禁的候选不公开安装包。
