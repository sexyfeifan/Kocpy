# Kocpy 0.1.8

0.1.8 修复旧版接管把日期/设备父目录和下层真实素材卷重复统计的问题，并将模糊的外部清单错误改为可解释、可处理的差异结果。此版本仍未使用 Apple Developer ID 签名与公证。

## 接管刷新修复

- 刷新会检测文件集合恰好等于下层卡卷并集的日期/设备父级汇总记录，移除该错误记录，只保留真实素材卷。
- 素材卷、文件数、容量、项目覆盖和收工进度在刷新后按真实卡卷重新计算。
- 只处理 Kocpy 本地接管记录，不移动、删除、改名或重新复制素材文件。
- 刷新只读取清单路径和大小，不重新计算素材哈希；完整清单接管仍会逐文件计算并比对哈希。

## 外部清单

- 支持 MD5、SHA-1、SHA-256，以及 Kocard MHL 使用的十进制 xxHash32。
- 正确处理 Kocard MHL 中以 `/` 开头的卡内相对路径。
- 只把素材卷根目录中的清单关联给该素材卷，不再误取下层其他卡卷的清单。
- 分别显示“缺少、额外、大小不同、校验值不同”，有真实差异的素材卷不计入收工达标。

## 真实项目验证

- 对“纸扎人阿岳”当前项目数据执行只读副本验证：29 条记录中确认 7 条为父级汇总，刷新后保留 22 个真实素材卷、2311 个素材文件、880,672,127,895 字节。
- 17 份外部清单中，15 份路径与大小完全一致；2 份存在真实差异：一份缺少 114 个文件，另一份额外 1 个文件。
- 验证和自动化测试均未写入项目素材或用户现有 Kocpy 数据库。
