# Kocpy 0.1.43

此版保留为未公开候选：实际桌面发现高级 fieldset 展开后滚动溢出，修复与全部功能继续随 0.1.44 发布。不改写已有标签，不推荐安装此候选。

## 折叠高级代理设置

- H.264 支持软件、自动、仅硬件模式；VideoToolbox 使用实际探测，自动模式仅在编码器兼容性失败时回退。显示实际编码器及回退原因。ProRes 为软件编码，提供 Proxy、LT、422、HQ。
- 支持帧率、音轨选择、音频编码／采样率／声道数、时间码、旋转、尺寸适配／裁切／拉伸；剪辑代理不允许丢弃全部音轨或时间码。
- 软件 H.264 可设置 CRF、速度、Profile 和 GOP；不兼容参数由主进程拒绝。BT.709 转换需完整源色彩信息，不是 HDR 色调映射。
- 3D .cube LUT 预检冻结 SHA-256，入队及执行前复核，限制 16 MiB；使用独占暂存副本，不修改原文件。
- 交付比较以冻结转换为目标，继续阻断意外帧率、时长、音轨与自定义尺寸异常；审计包含参数和实际编码器。

## 验证边界

合成样本与回归不是所有素材或 NLE 兼容认证。硬件能力依机器而异；无 Developer ID 签名及 Apple 公证。正式附件结果见验证记录。
