# Kocpy 0.1.33

真实双 Mac 交换验收修复候选。

- 修复工作站导入后首次重启会静默补齐项目默认字段、从而无操作增加工作区修订并改变摘要的问题。
- 导入事务现在先规范化全部外来项目，再以同一份规范状态计算交换摘要、写入恢复日志并提交权威工作区。
- 新增回归：旧形状项目导入后，重启前后的修订、摘要和项目内容必须完全一致。
- macOS 安装包按目标架构裁剪媒体运行时：arm64 包只保留 arm64 FFmpeg，x64 包只保留 x64 FFmpeg；裁剪后再次核对来源、架构、摘要、系统动态库和 GPL 许可。
- 保留 0.1.32 的可访问动效以及 0.1.31 的稳定工作站身份、只读预检、默认保留本机、逐项冲突选择、删除墓碑和可恢复审计。

## 候选状态与发布门槛

Mac B 已在 0.1.32 证明新增、精确重复、冲突默认、选择性采用外部、远端删除与墓碑符合设计，但重启一致性失败，因此 0.1.32 不发布。0.1.33 必须在两台真实 Mac 上复验重启稳定，并完成 B→A→B 返回闭环；双架构 CI、安装包回下载、严格签名及包内运行时核对也必须通过。门槛关闭前不创建正式标签或公开 Release，latest 保持 0.1.30。

本版本仍无 Developer ID 签名／公证。ad-hoc 签名只保证应用包结构完整，不能替代 Apple 身份、公证或用户来源确认。双机测试只使用隔离合成元数据，不读取、迁移、修改或删除生产素材。
