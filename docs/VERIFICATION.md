## 自动测试覆盖

1. 两目标真实拷贝、空文件、空目录、源文件修改时间不变。
2. 第一目标已存在同内容文件，仍能完成第二目标，且完整校验。
3. 同名不同内容不覆盖；其他目标可成功，任务整体明确失败。
4. 同名冲突创建带后缀的新副本。
5. 拒绝源/目标相同、嵌套和符号链接别名。
6. 拒绝通过目标内部符号链接写回源。
7. 源含符号链接明确报错，不静默跳过。
8. 取消不显示成功；重试重新校验且计数正确。
9. 拒绝重复启动与删除进行中任务。
10. 失败任务不阻塞队列后续任务。
11. 目录备份保留目的地额外文件。
12. 项目/日期/机位目录与唯一备份目录。
13. 空源不能显示为已校验成功。
14. 拒绝不支持的哈希算法和零目的地。
15. 不支持硬链接时，模拟 ENOTSUP，走真实独占复制回退路径。
16. 清理并恢复本任务上次中断留下的临时文件。
17. 并发持久化串行执行，损坏主文件能从上一份 .bak 恢复。
18. HTML 报告正确转义不可信名称，失败状态不伪装成功。
19. 内置 FFmpeg 实际生成 H.264 与 ProRes Proxy，再完整解码验证。
20. 旧 JSON 任务与项目可重建 SQLite 索引，分页检索和损坏索引备份恢复通过。

## 桌面应用实际操作

- 使用打包后的 `Kocpy.app`（非浏览器假接口）打开全部七个页面。
- 用生成的 640×360 测试视频与文本文件，从三步向导发起一次双目标备份。两个目标均 SHA-256 一致。
- 检查任务详情、目的地路径、校验日志与素材库清单。
- 从素材库使用打包内置 FFmpeg 生成 H.264 代理，返回实际文件路径。
- 创建项目、归档项目，重启后记录保留。
- 深色/浅色主题保存、切换，最后恢复深色。
- 原生保存对话框导出 PDF；检查中文和长哈希/路径表格排版。
- 最终构建重新启动，任务历史恢复正常；二次启动进程立即退出，仅保留一个主实例。
- 仅使用自建测试文件，未向用户正式素材或原两个项目写入。

本机界面中保留了一条明确命名为「功能自检 · 双目标备份」的真实测试记录和一个已归档测试项目，方便查看完成态。安装包本身不包含这些用户数据。
