# Kocpy 0.1.41

## 可配置并行代理

- 默认及每批并行数可选自动、1、2、3。旧工作区保持默认单任务；新工作区自动最多 2 个。
- 队列总上限可即时调整，降低上限不终止当前运行任务；机械盘、网络盘及未知介质同设备串行，磁盘识别失败全局保守串行。
- 独立任务控制器保证取消、暂停只影响指定任务。备份优先会等待全部代理安全暂停，结束后只恢复备份暂停的任务。
- 持久化失败停止启动新任务，支持明确重试保存后恢复；仍保留完整源哈希和独占输出发布。

## 验证边界

合成媒体并行生成及独立取消、队列调度回归已执行。真实机械盘、NAS/SMB、多外置盘性能不计为通过。无 Developer ID 和 Apple 公证；准确安装包验证见同版验证记录。
