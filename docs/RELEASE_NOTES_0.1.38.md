# Kocpy 0.1.38

Kocpy 0.1.38 集中处理后台任务可见性与项目归档联动。数据安全边界没有放宽：项目归档只改变 Kocpy 记录的默认可见范围，不删除任务、素材、报告、校验结果或磁盘文件。

## 后台任务

- 左侧新增“后台任务”，统一显示素材备份、代理、独立归档转存、接管、复校验、修复、报告／交付生成和诊断任务。
- 首页“后台活动”只保留正在运行或等待处理的项目；无活动时使用紧凑状态，不占据大块空间。
- 独立页面可按状态、任务类型和项目筛选，显示总体与当前文件进度、源／目标、速度、预计时间、结果与错误，并可返回原功能处理。
- 原来重复出现在各页面顶部的操作历史区域已移除；即时成功／失败通知仍短暂显示，当前会话消息和持久化历史集中到后台任务页。
- 0.1.37 及更早操作记录缺少新增进度字段时仍可读取，只显示当时实际保存的证据。

## 独立归档转存进度

- 明确区分扫描、复制、目标回读和报告生成阶段。
- 4 MiB 分块传输期间约每 250 毫秒更新一次，显示当前相对路径、单文件字节、整体字节、完成文件数、当前／平均速度、已用时间和预计剩余时间；整体进度把复制与目标回读作为两个必须完成的阶段连续累计，不会在切换到校验时倒退。
- 复制速度表示写入目标的传输速度；回读速度表示重新读取目标并计算 SHA-256 的速度。报告阶段、停止状态和阶段切换会清零速度与剩余时间。
- 单文件进度只存在于当前运行会话，不连续写入持久记录；原有独占写入、目标身份检查、检查点、恢复和 SHA-256 安全规则保持不变。

## 模板与归档项目

- “项目模板与交接”中的模板管理默认折叠；本次运行期间记住展开状态。模板编辑器打开时保持展开，交接表单始终独立可见。
- 项目归档后，关联传输历史与素材库记录退出默认的“当前项目”范围；可切换“已归档”或“全部范围”继续查看风险和历史。
- 恢复项目后相关记录自动回到默认范围，无需重新扫描或接管。无项目的普通任务不受影响。
- 项目仍有等待、复制、暂停、校验、自动报告、当日交付、代理、归档转存或对应维护操作时，主进程拒绝归档并引导到后台任务页。已经停止的失败历史可以随项目归档，风险记录不会被隐藏或改写。

## 兼容与安装边界

- 不进行破坏性数据迁移，不改变备份任务、素材库或归档转存的持久化身份。
- 提供独立 Apple Silicon（arm64）与 Intel（x64）安装包及 `SHA256SUMS.txt`。
- 当前仍没有 Developer ID 签名和 Apple 公证。安装包使用 ad-hoc 签名；SHA-256 只证明下载内容与发布附件一致，不代表 Apple 身份认证或公证。
