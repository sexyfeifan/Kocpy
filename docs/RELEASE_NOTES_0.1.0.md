# Kocpy 0.1.0

0.1.0 是 Developer ID 签名前的首个完整工作流校验版本，覆盖现场接收、代理交付、长期归档、标准化项目和多工作站元数据协作。

## 新增

- 目的地文件夹可直接拖入；支持扫描并接管既有备份，以外部清单、接管时基线或未验证结构明确标记可信度。
- 项目卡片改用“素材覆盖”表达，区分 Kocpy 接收、外部接管、已验证、副本达标与待处理，不对未知历史量推测百分比。
- SQLite/WASM 本地索引、分页搜索、索引备份恢复和旧 JSON 数据兼容迁移。
- 按项目、拍摄日、任务和单文件复校验；归档变化时间线、修复、位置迁移、周期提醒和变化报告。
- 广告、纪录片、短片、综艺、电影内置模板；开工/收工检查表、制作人员、交接签名、NAS 预设和网络性能检查。
- 自定义代理分辨率、码率、封装、命名；暂停、恢复、重试；时间码、帧率、音轨、色彩空间、缩略图和波形检查。
- 一键生成代理交付目录，包含媒体、Resolve/Premiere/Final Cut 清单和 SHA-256 交付检查报告。
- 工作站包完整性校验、冲突合并及带随机令牌的局域网只读项目索引；不默认同步原素材。
- 完成后自动报告、交付清单、通知和安全推出；缩略图缓存容量限制。
- 应用内“软件使用说明书”，逐模块提供操作步骤、安全原则和直达入口。

## 可靠性说明

- 仍为未签名、未公证构建；首次打开可能需要在 Finder 中右键选择“打开”。
- 睡眠期间由系统电源断言保护活动传输；异常退出后从持久化检查点恢复。
- 真正的 SMB/NAS 长时网络抖动和不同现场硬盘型号仍应在目标制作环境中按硬件测试手册执行。
