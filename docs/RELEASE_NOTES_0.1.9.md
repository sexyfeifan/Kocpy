# Kocpy 0.1.9

0.1.9 修复默认窗口或较小窗口遮挡侧栏入口、页面板块和操作区域的问题。此版本仍未使用 Apple Developer ID 签名与公证。

## 窗口与响应式布局

- 启动时读取当前显示器的可用工作区域，默认窗口最大为 1480 × 960，并保证完整位于屏幕内。
- 标准最小尺寸为 1080 × 720；显示器工作区域更小时自动采用实际可用尺寸作为安全下限。
- 1000 像素及以下高度启用紧凑侧栏，保留全部 11 个模块、偏好设置、检查更新和作者入口。
- 左侧导航可以独立安全滚动，极端情况下也不会永久裁掉底部入口。
- 窄窗口中的项目、存储、统计卡片自动减少列数；大型项目矩阵与素材卷明细使用横向滚动。
- 新建备份、项目编辑和详情弹窗限制在窗口内部，过长内容使用弹窗内部滚动。

## 验证

- 窗口尺寸计算测试覆盖 1728 × 1080、1280 × 800 和 1024 × 680 三种显示区域。
- 使用隔离数据实际启动 Electron 界面，验证默认窗口与 1080 × 720 最小窗口。
- 两种尺寸下，工作台到使用说明的全部模块、偏好设置、更新入口和作者入口均可见；主内容区可正常滚动。
