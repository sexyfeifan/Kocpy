# Kocpy 0.1.20

安全判定、媒体依赖分发与界面布局维护版本。

## 安全与收工检查

- 已声明使用的设备存在失败、暂停、未验证等任务时，不再漏报待处理事项。
- “休息日 / 当天未使用”只解释没有素材记录的单元，不再遮盖已经记录的素材风险。
- 不再将不同卷 UUID 直接视为不同物理磁盘。完整回读后记录同次系统拓扑检查，归并分区与 APFS 底层磁盘；阵列、网络和未知关系保守计数。
- 多目标旧任务可能显示独立性证据不足；原哈希记录不删除，也不代表素材损坏。重新校验在线目标可更新存储关系。系统拓扑不证明机箱、供电或灾备独立。
- 任务详情和报告区分通过校验的目标数与可计数副本数；未解决的外部清单差异不显示无条件的完成结论。

## 媒体与分发

- 两种架构统一采用固定源代码构建的 FFmpeg 9.0.1 与 x264，移除旧 nonfree 构建。
- 包含完整许可证、精确对应源码、构建脚本、构建信息和摘要；对应源码包与安装包一起提供。Kocpy 本身的 MIT 许可不变，独立媒体运行时遵循其 GPL-2.0-or-later 条款。
- 修复成功探测时丢失媒体时长、帧率与音轨信息的问题，恢复相关波形生成。
- 修复启动前已取消的代理任务等待不结束，以及取消后过早清理临时输出的问题；最终代理发布使用禁止覆盖的文件操作。
- 发布流程先完成两个架构的检查，统一形成含安装包、源码及 SHA-256 的草稿；最终安装包验收后才公开，不覆盖旧附件。

## 界面

- 整理代理范围、收工项目条目、交接检查表、提醒与归档复校验的间距、按钮高度和换行。
- 主窗口正常状态使用 1.4–2.0 的宽高比范围，常规屏幕最小 1080×720；小屏自动适配可用区域，全屏交由系统管理。
- 侧栏文字与图标保持固定尺寸；低高度通过独立滚动访问全部功能。
- 使用说明仍默认折叠，用户点击才展开。

## 安装与验证边界

此版本没有 Developer ID 签名或公证。安装与实际验证范围请查看 [验证记录](https://github.com/sexyfeifan/Kocpy/blob/main/docs/VERIFICATION.md)，安装包摘要见本 Release 的 SHA256SUMS.txt。

测试使用生成素材和隔离目录；不以 Rosetta 代替用户现场 Intel、NAS 或真实拔盘验证，不承诺零缺陷或所有相机格式兼容。备份与校验完成不等于可以格式化原卡。
