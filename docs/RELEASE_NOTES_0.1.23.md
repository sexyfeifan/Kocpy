# Kocpy 0.1.23

专业项目日常操作与证据链维护版本。

- 项目每日计划新增实际操作人和追加式决定记录；“应该有素材”“当天未使用”“休息日”与恢复待确认均保留日期、设备／机位、操作人、时间和规则版本，未知状态不被自动推断。
- 支持按拍摄日加入临时设备／机位，不把临时航拍、录音或外部设备扩散到整个项目周期。
- 项目规则建立不可变版本快照。设备、机位、目的地、副本要求、命名、完成动作或检查表变化时要求修改人并追加版本；后续更新不改写既有素材卷、检查表签署或交接证据。
- 模板加入修订号和应用审计：保存模板应用人、模板版本、选择的字段、复合配置的真实前后值及结果规则版本。
- 备份任务保存逻辑素材卷身份和操作尝试。失败目标重试、异常恢复仍属于同一素材卷，项目覆盖、收工矩阵和素材卷明细不会按尝试次数重复计数；成功目标不会因另一目标失败而重写。
- 项目交接可选择单个拍摄日或整个项目。记录冻结当时规则版本、逻辑素材卷数、达标数、待处理和待确认单元，并可保存例外说明；单日交接只统计该日素材。
- 多工作站工作空间合并保留规则版本、每日决定、模板应用、检查表与交接历史，不以较新的配置对象静默覆盖整段审计记录。
- 项目详情显示当前规则版本、每日决定、模板应用和历史规则素材卷数量；项目编辑器明确提示规则追加语义，软件内与公开使用说明同步更新。

安全边界没有降低：逐文件哈希、每个目标独立回读、物理独立副本判断、源卷身份、路径边界和恢复检查保持不变。规则与交接记录是本地可追溯证据，不是第三方数字签名。

所有写入测试与 GUI 验收使用隔离生成数据，不修改用户生产项目、素材或原始清单。真实 NAS、拔盘、断电及全部相机格式未全面验证。无 Developer ID 签名／公证，不宣称零缺陷或硬件认证。最终发布事实与附件摘要以 [验证记录](VERIFICATION.md) 为准。
