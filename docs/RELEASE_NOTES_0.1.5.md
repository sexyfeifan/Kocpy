# Kocpy 0.1.5

0.1.5 修复并完善既有备份接管，使目录识别与项目创建时的路径规则保持一致。此版本仍未使用 Apple Developer ID 签名与公证。

## 接管既有备份

- 整个项目：识别有效拍摄日期文件夹，并按设备、可选 A–E 机位和素材卷逐级建立独立任务。
- 单日所有机位：在选定拍摄日内分别接管所有设备、机位和素材卷。
- 单张素材卡：把所选文件夹作为一个素材卷，并从上级目录推断日期、设备与机位。
- 支持 `FX3_202608291430` 等时间戳素材卷名称，不再要求 `CARD01`、`ROLL01` 等固定格式。
- 使用项目自定义命名规则解析层级，支持设备与日期等字段的自定义顺序。
- 无效日历日期不会被当成拍摄日；项目配置外的设备会在接管预览中明确提示。

## 项目进度与报告

- 接管任务持久化保存机位信息。
- 项目素材矩阵按“设备 × 机位”分别统计，避免 A/B 等机位合并。
- 旧任务缺少机位元数据时显示为“未标机位”，不推测或伪造归属。
- 项目 PDF 的日期设备矩阵同步展示独立机位。
