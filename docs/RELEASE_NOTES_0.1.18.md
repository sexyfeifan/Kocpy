# Kocpy 0.1.18

交互安全、状态反馈与完整工作流程改进。包含本地 0.1.17 的镜像目录、拖拽和传输实时状态修复。

## 范围与安全

- 单卷/单文件复校验必须明确选择；后台拒绝缺参、越界相对路径和不存在的记录，不隐式扩大范围。
- 批量创建以请求 ID 和逐项提交状态避免重试重复；部分失败可继续未提交项。
- 路径预览、目录预创建和实际复制共用命名规则；项目与模板一致支持自定义机位名称。
- 检查表按拍摄日逐项确认，收工检查再次检查副本与使用状态；交接填写实际操作人，失败不清空。
- 修复前确认来源、目标、身份、文件范围与保留方式；部分结果保持可追溯。
- 维护操作登记、互斥、退出保护和中断记录；写入诊断禁用于标记的素材介质，并明确有限测试范围。

## 状态与反馈

- 取消不是成功，错误与详细结果可回看；维护后统一刷新任务、项目和目录。
- 复校验不会重复触发完成后生成代理或推出设备；素材索引写入完成后再刷新界面。
- 接管切换范围重新预览，完整展示全部卷；后台进度在切页后仍可查看。
- 素材库区分加载/无结果/错误和副本可访问性，每页 100 条，不按传输字节刷新查询。
- 恢复中心明确“刷新记录”不等于磁盘校验，接管素材分流到基线/清单处理。
- 顶层弹窗焦点与快捷键保护；完成消息不抢焦点；设置草稿和主题保存语义一致。

## 日常效率

- 代理暂停可取消，源/输出/依赖可见，入队与完成区分；交付限定来源卷及已完成代理。
- 报告选择日期/项目，批量推出预览盘列表并展示逐盘结果。
- 模板/NAS 删除再次确认，冷归档先说明卸载范围。
- 提醒支持修改/停用/删除；NAS 可编辑并直接选用；LAN 索引支持图形化只读连接，令牌默认隐藏。
- 项目提供模板交接入口，侧栏保持固定字号，窄窗口允许滚动与换行。
- 应用内帮助支持搜索、上下文入口及基线/差异就地解释，默认仍折叠。
- 使用手册、公开说明与版本号同步更新。

## 数据安全边界

不降低目标独立回读、来源哈希、磁盘身份、MHL 审计或原损坏文件保留要求。关闭详情不是取消后台操作；提交阶段不能强制终止。133 项自动化测试通过，3 项可选环境测试跳过；两份安装包通过镜像完整性及打包运行时检查。完整范围见 [验证记录](https://github.com/sexyfeifan/Kocpy/blob/v0.1.18/docs/VERIFICATION.md)。

无 Developer ID 签名或公证。Apple Silicon 与 Intel 安装包分别提供；Rosetta 的 x64 测试不能替代真实 Intel Mac。由于本轮桌面锁定，真实拖拽、键盘焦点、深浅主题和最小窗口仍须人工验收，不宣称全部现场场景已验证。
