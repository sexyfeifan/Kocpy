# Kocpy 0.1.53

## 更简洁的内置说明

- 软件内只显示当前安装版本的一条更新摘要，默认收起；不再排列历史版本和未发布候选。当前版本取自应用版本，避免更新摘要停留在旧版本。
- 功能标题和操作说明不再附带功能产生时的 Kocpy 版本号；历史代理缺少证据等重要安全提示保留，改用当前状态说明。
- GitHub 历史发布、验证记录和原安装包保留，不删除、不覆盖。说明仍只在用户点击后展开。

## 布局与留白

- 恢复中心统计／任务列表、诊断中心磁盘卡片增加外层留白与卡片间距，长名称、路径和操作区按可用空间换行。
- 设置页居中布局，宽窗口使用两列，默认和窄窗口使用单列；保存按钮、关于和作者平台底栏跨列完整显示。
- 不缩小侧栏字体或图标；备份、校验、身份、恢复、报告和项目数据逻辑不变。
- 仅执行只读恢复检查后关闭窗口不再误报“未提交输入”；真正勾选恢复确认后的离开提醒及重试授权仍保留。

## 发布与验证

0.1.53 已正式公开，Apple Silicon／Intel 安装包、媒体对应源码与 SHA-256 清单由同一流水线生成，草稿回下载核对后公开。两种原生架构各949项回归通过、4项条件跳过；类型、构建、来源／许可、签名结构、包内运行与准确arm64桌面验收通过。普通／项目隔离备份、回读和自动PDF完成，合成源内容及时间／身份未变。

验证详情见[验证记录](VERIFICATION.md)；原生Intel桌面、Rosetta桌面及真实双独立盘／NAS／双Mac没有新增本版认证。当前仍为ad-hoc签名，没有 Developer ID／Apple 公证。升级前正常结束任务并退出旧版，核对同版摘要后手动替换应用。
