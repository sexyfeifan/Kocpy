# Kocpy 0.1.10

0.1.10 将接管项目中的外部清单差异从只读错误提示升级为可审计、可操作的处理流程，并按实际制作顺序重排左侧功能。此版本仍未使用 Apple Developer ID 签名与公证。

## 外部清单差异处理

- 素材卷明细中的红色差异状态可点击，显示缺失、额外、大小不同和校验值不同的全部相对路径。
- 可直接在 Finder 中显示素材卷目录、外部 MHL/SHA 清单或具体差异文件。
- 缺失文件可从用户选择的同卷健康副本补回；Kocpy 在写入前验证全部候选文件的路径、大小与清单哈希，任何一项不符都不会开始写入。
- 补回过程使用临时文件并验证写入结果，完成后自动对整卷重新计算并比对外部清单；只有整卷通过才恢复绿色状态并计入收工副本。
- 单纯的额外文件可在已建立完整首次哈希基线后由用户明确确认。原 MHL 不会被修改，原始差异、确认时间和说明保留在任务审计日志中。
- 缺失、大小不同和校验值不同不能通过人工确认跳过。
- 刷新接管信息时，只有差异集合完全没有变化才保留既有的额外文件确认；内容发生变化会重新要求处理。
