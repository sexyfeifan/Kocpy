# Kocpy 0.1.4

0.1.4 完成从现场接收到长期归档、代理交付、大型项目索引和多工作站元数据协作的完整本地工作流。此版本仍未使用 Apple Developer ID 签名与公证。

## 可靠接收与诊断

- exFAT、APFS、HFS+、网络挂载路径统一使用安全临时发布、独立回读哈希和卷身份检查。
- 支持拔盘/目标失联、空间不足、系统睡眠、异常退出、暂停恢复和仅失败目标重试；睡眠前保存检查点，唤醒后要求确认设备。
- 诊断中心新增大文件与 1000 个小文件的实体卷可靠性验收，保存文件系统、速度、耗时和通过状态；诊断包继续脱敏。
- 真实外置 APFS 双盘，以及隔离的 APFS、exFAT、HFS+ 挂载卷压力测试均已通过。

## 代理与交付

- 代理预设可保存、更新、删除；支持自定义分辨率、码率、封装和命名规则。
- 代理队列支持依赖链、暂停、继续、失败重试、自动完成动作，并保留原任务和相对路径关联。
- 检查时间码、帧率、音轨和色彩空间；后台生成缩略图与波形。
- Resolve、Premiere、Final Cut XML 与完整交付目录使用真实媒体时长、帧率和画面尺寸。

## 长期归档与项目标准化

- 支持整盘、项目、拍摄日、素材卷和单文件复校验，记录吞吐、风险、缺失、修改、移动、修复和未登记新增文件。
- 可从健康副本修复损坏副本，保留原损坏文件；支持周期提醒、变化报告和项目冷归档/恢复。
- 项目可自定义目录命名规则、开工/收工标准、制作人员、完成动作、NAS 预设和网络健康轮询。
- 接管既有备份支持单卡、单日全部机位和整个项目，区分外部清单、接管时基线和未验证结构。

## 大型项目与协作

- SQLite/WASM 本地目录数据库保存完整任务、项目和文件 JSON；旧 JSON 自动迁移并保留兼容镜像。
- 素材库分页与增量搜索、报告流式生成、缩略图容量限制、数据库轮换备份与损坏恢复。
- 项目冷归档可卸载热数据；10 万与 100 万文件索引压力测试通过。
- 工作站配置包包含完整性校验、导入前快照、项目/任务/归档变化合并与重复卷冲突检测；局域网索引只共享脱敏元数据。

## 界面与使用说明

- 修复项目卡片操作拥挤、PDF 汇总排版、诊断/归档卡片留白、素材重新定位和 Finder/播放入口。
- 普通备份镜像模式原样复制；非镜像模式使用“源卷名_时间戳”，不覆盖已有文件。
- 应用内使用说明覆盖备份、恢复、项目、接管、素材库、代理、报告、存储、诊断、归档、NAS、协作和大型数据库维护。

## 平台与安全

- Electron 44、electron-vite 5、Vite 7；生产与开发依赖审计为 0 个已知漏洞。
- 继续提供 Apple Silicon 与 Intel 两种 DMG。Developer ID 签名与 Apple 公证将在证书可用后执行。
